Player support

For help with The Comfy Gambit or Neon Chambers, email abdmaher01@gmail.com. Tell us which game you play so we can find the right answer.

Report a puzzle or a technical problem

Include the puzzle or chamber number, your device model, the game version if known, and what happened after your last move. A screenshot is helpful if you have one.

Purchases

The Comfy Gambit Premium is a one-time Google Play purchase. If you have previously purchased it, launch the game using the same purchasing Google Play account and allow the store to restore or recognize the entitlement. If an owned Premium offer still appears, or an earned ad reward fails to arrive, please report the game version and what happened. For other purchase issues, name the game and item. Never send passwords, payment-card numbers or complete receipts.

Data and account deletion

Email abdmaher01@gmail.com with the game name and the records you want removed. The Comfy Gambit does not require a player account, but its Daily Match leaderboard uses a device-stored guest ID; include the short public guest ID if you have it so that we can locate a leaderboard record. Android’s Clear storage action removes local saves, not Cloudflare-hosted rankings or a Google Play purchase. See each game’s policy for the provider and deletion details.
